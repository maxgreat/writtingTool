# Dictionaries

Hunspell dictionaries bundled into the app, checked in Rust with
[spellbook](https://github.com/helix-editor/spellbook) (`src-tauri/src/dictionary.rs`).
They come from [wooorm/dictionaries](https://github.com/wooorm/dictionaries), as published on npm;
each folder keeps its `license` file.
